# Warung Api — Fire Stall

[![make.fun](https://make.fun/badge/best-cooking-game-20261125-0137.svg)](https://make.fun/c/best-cooking-game-20261125-0137)
[![rank](https://make.fun/badge/best-cooking-game-20261125-0137/mrsaepudin40/warung-api/rank.svg)](https://make.fun/c/best-cooking-game-20261125-0137)
[![reward](https://make.fun/badge/best-cooking-game-20261125-0137/mrsaepudin40/warung-api/reward.svg)](https://make.fun/c/best-cooking-game-20261125-0137)

Run a street-food warung at dinner rush. Tickets land on the order board with a
countdown — grab ingredients from the pantry, chop them on the board, toss them
in the wok, serve inside the green heat window or the dish burns, plate it and
serve it before the ticket dies. Three serves in a row build a combo tip.

- **Nasi Goreng** — rice + egg + chopped chilli
- **Mie Goreng** — noodle + egg + chopped veg
- **Ayam Geprek** — chopped chicken + chopped chilli
- **Sate Ayam** — chopped chicken + sauce

WASD / arrow keys to move, E or click to interact, R to cook again, M to mute.
Runs offline from static files — no network, no assets, WebAudio bleeps only.

Entry for the [best cooking game](https://make.fun/c/best-cooking-game-20261125-0137)
bounty on make.fun.
